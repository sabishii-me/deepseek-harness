# 实验性 Shisa 账号 UI

[English](README.md) | 中文

## 使用方式

在 DSH web profile 中与 shisa-provider 一起挂载。打开 Settings → Models → Shisa，再点击登录 Shisa。真实批准地址在独立浏览器标签页打开；页面同时显示用户码。取消会停止 Host 授权。连接后显示组织和模型目录数量；退出登录撤销设备凭据。此 UI 独立于 Jouzu。

## 模型体验

页面仅调用账号 RPC，不提交提示词、不修改默认模型，也不恢复 Session。密钥不进入组件状态。

## 已知限制与后续工作

等待期间每 1.5 秒轮询一次无密钥状态。关闭页面停止 UI 轮询，但授权仍在进行；重新打开可查看或显式取消。真实账号批准和推理需要用户参与。

## 首次登录引导

插件注册官方单一插槽 `settings.models.sign-in`。首次使用可选择登录 Shisa、进入原有 DeepSeek API key 编辑器或稍后配置。引导与 Models 账号卡片复用同一 Host 授权 Remote，仅在授权成功且模型目录非空后自动完成；离开弹窗前取消未完成的登录。部署配置应明确选择一个引导提供者，不与其他同插槽贡献同时加载。卸载后若无其他贡献者，恢复宿主默认界面。

目录行使用紧凑的 ID／名称双列布局，展开后以只读文本显示参数。模型及端点全部来自 Shisa catalog，不提供添加、删除、编辑、Cancel／Apply，也不将只读数据伪装成输入框。仅参考内置供应商的布局及 DSH 样式令牌。
