# 实验性 Jouzu 会话 UI

[English](README.md) | 中文

## 使用方式

在 web profile overlay 中与 jouzu-backend 一起显式启用。插件使用现有会话输入区及按名称分派的工具调用插槽。原生 DSH 会话不显示 Jouzu 工作面板。不包含模拟开关、场景数据或独立聊天面板。

## 工作展示

工作区域与原生 DSH Todo 使用同一 TaskList 组件，读取 jouzuActivity，显示记录中的未完成任务、后台执行及依赖。空记录或全部结束时不渲染。结束结果保留在普通工具历史中。历史运行回执标为最近记录运行中，不用动画表示已确认的实时执行。不根据不完整记录推断任务总数或完成比例。

TaskCreateMany、TaskCreate、TaskUpdate、TaskList、bg_task 和 agent_wait 在现有会话中使用专属工具视图。原生问题继续使用标准 DSH 问题输入区。工作区域不展示原生诊断及传输阶段。Session 检查 API 仍可供显式诊断消费者使用；渲染本插件不会调用它。

## 模型体验

UI 不添加模型输入、工具、调度器或取消操作，不改变 token 统计或 KV 缓存策略。任务仍由 Jouzu 所有；共享 Todo 展示不将原生工作转为 DSH 任务。

## 已知限制与后续工作

观察记录基于回执，不是权威原生任务清单。旧的纯文本工具结果缺少后台元数据，无法自动重建。后台完成通知只通过匹配确切的原生执行身份更新已有执行。Pi RPC 不提供终端组件 widget 工厂。本插件不提供 job 取消及 Flow 修改控制。DSH 前台停止不声称取消后台 job。精确匹配恢复限制及支持的输入类型仍由 jouzu-backend 负责。完整真实工作及平台资格验证仍待完成。

已完成的后台工作保留在独立结果区，使用原生完成回执；不由前台结算推断。原生回执标题保持可见，包含提供时的退出状态。前台停止与后台任务停止仍是不同操作。

## Live progress

Jouzu 会话在 DSH 报告运行后立即在 composer 上方显示运行指示。在 assistant 响应活动期间，同一区域按到达顺序显示来自官方 Chat 快照的推理内容，独立于转录折叠。它在结算时清除，绝不复用已完成 assistant 的推理。原生转录/历史渲染不变。此视图只使用公开的 Session 与 Conversation 钩子；它不创建额外传输、不存储推理副本、不产生 Host 事件。
